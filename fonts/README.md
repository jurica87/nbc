# Locally hosted camp fonts

The camp pages use Oswald (headings) and Inter (body), matching the existing athletics page without loading Google Fonts from visitors' browsers.

Original Latin WOFF2 fonts obtained from the Google Fonts stylesheet. Original SIL Open Font License files are included alongside the fonts. No glyphs or logos have been altered.

- `oswald-latin.woff2`: https://fonts.gstatic.com/s/oswald/v57/TK3IWkUHHAIjg75cFRf3bXL8LICs1_Fv40pKlN4NNSeSASz7FmlWHYg.woff2
- `inter-latin.woff2`: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
